# Weatherly — Weather Dashboard

A responsive frontend portfolio project built with HTML, CSS, and JavaScript.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. Explore the UI and interactions.

## Stack
- HTML5
- CSS3 (responsive layouts, animations)
- Vanilla JavaScript

This is a portfolio/demo project. Replace demo text, contact details, and assets with your own before publishing.
